# CommunityMap

Upcoming activities in a community on a map, with spots-left markers, clusters and a summary card.

- **Provide:** `items`: `{x, y, label, title}` for an activity marker ("6 left") or `{x, y, cluster}`; `selected` (index) and `card` for the summary.
- Only upcoming activities with spots appear; sold-out and started ones leave the map (Maps FR-010).
- Pair with a List / Map `Segmented` toggle on C1 (PRD A6).
