# AppHeader

The web app's header: wordmark, section links, Host / Booker role toggle, account.

- **Provide:** `role` (`booker` · `host`), `current` (the active link), `user`, `signedIn`, `compact` (invite pages: wordmark only).
- The role toggle switches the interface, not permissions (PRD W1).
- The wordmark is set in the display face: no Velio logo files were supplied.
