# Chip

Small labels for invite status, how someone joined, and community.

- **Provide:** `children` and `tone`: `neutral` (default, `line`), `lime`, `sky`, `forest`, `outline`, `danger`.
- **Fixed meanings:** invite status Created = neutral, Opened = sky, Claimed = lime. Source Direct = neutral, Vouch ("Via Tunde") = lime, Public link = sky. Community = outline.
- Every chip carries a word; colour never stands alone.
