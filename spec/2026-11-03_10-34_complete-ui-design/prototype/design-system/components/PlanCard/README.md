# PlanCard

One Plan in My plans: the activity, date, members and booking reference.

- **Provide:** `title`, `scene`, `date`, `place`, `members`, `memberTotal`, `code` (upcoming), `removed`, `past` with `attended`.
- Upcoming shows the booking reference; past shows Went or No-show from the host's marks; removed shows a `danger` chip.
- Links to the Plan (B4). My plans is B6, PRD L2.
