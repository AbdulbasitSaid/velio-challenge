# velio_api

Dart client for the Velio API, generated from `packages/contracts/openapi.json` by `openapi-generator` (`dart-dio`, `json_serializable`). Used by `apps/mobile` (S7).

Regenerate with `bun run contracts:dart` from the repository root. Don't edit `lib/`: CI regenerates it and fails on any difference. `pubspec.yaml`, this README and `analysis_options.yaml` are kept by hand (`.openapi-generator-ignore`).
